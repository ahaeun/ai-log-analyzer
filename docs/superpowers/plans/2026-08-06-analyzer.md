# analyzer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `analyzer/` FastAPI service that receives error events from `watcher`, analyzes them with OpenAI, suppresses duplicate Slack alerts via Redis, sends the alert, and hands the result off to `dashboard` for storage.

**Architecture:** A single ingestion endpoint (`POST /api/errors`) validates the `X-API-Key` header and request body, immediately returns `202`, and schedules the actual work via FastAPI `BackgroundTasks` — since the combined OpenAI + Redis + Slack + dashboard round-trip can exceed `watcher`'s 5-second HTTP timeout. Four small client modules (`openai_client`, `dedup`, `slack_client`, `dashboard_client`) each wrap one external call and fail soft (never raise past their own boundary except where explicitly noted); `processor.py` orchestrates them in sequence. `watcher.models.ErrorEvent` is imported directly rather than redefined, since the incoming schema is identical to what `watcher` already sends.

**Tech Stack:** Python 3, FastAPI, `openai` SDK, `redis` (redis-py), `requests`, `pytest`, Docker Compose (for a local Redis instance).

## Global Constraints

- 담당 범위는 `analyzer/`와 그 테스트(`tests/analyzer/`)로 한정한다. `watcher/`, `dashboard/`는 읽기 전용으로 import만 하고 수정하지 않는다.
- API 키(`ANALYZER_API_KEY`, `OPENAI_API_KEY`, `DASHBOARD_API_KEY`)는 하드코딩하지 않고 환경변수에서만 로드한다.
- `analyzer` 자체의 설정(환경변수) 누락은 즉시 `ValueError`로 실패시킨다 — 조용히 무시하지 않는다.
- `POST /api/errors`는 `X-API-Key` 헤더가 `ANALYZER_API_KEY`와 일치해야 한다. 불일치/누락 시 401 — 요청 바디 검증(422)보다 먼저 확인되어야 한다 (FastAPI의 `Depends`를 라우트 데코레이터의 `dependencies=[...]`로 등록해 바디 검증보다 먼저 실행되게 한다 — `dashboard` 구현 중 발견된 것과 동일한 순서 버그를 처음부터 피한다).
- OpenAI 호출이 실패해도 예외를 밖으로 던지지 않고 `ai_analysis=None`으로 계속 진행한다.
- Redis 연결 실패 시 중복 여부를 "중복 아님"으로 안전하게 간주하고 계속 진행한다.
- Slack/dashboard 호출이 실패해도 예외를 밖으로 던지지 않고 로그만 남긴 뒤 계속 진행한다 (재시도 큐는 이번 범위 밖).
- Redis 중복 판정으로 Slack 알림이 억제된 에러도 dashboard에는 `notified=false`로 저장한다 — 저장 자체를 건너뛰지 않는다.
- `watcher.models.ErrorEvent`를 그대로 import해서 사용한다 — 별도로 재정의하지 않는다.

```python
import os
from dataclasses import dataclass

REQUIRED_ENV_VARS = (
    "ANALYZER_API_KEY",
    "OPENAI_API_KEY",
    "REDIS_URL",
    "SLACK_WEBHOOK_URL",
    "DASHBOARD_URL",
    "DASHBOARD_API_KEY",

class AnalyzerConfig:
    api_key: str
    openai_api_key: str
    redis_url: str
    slack_webhook_url: str
    dashboard_url: str
    dashboard_api_key: str


def load_config_from_env() -> AnalyzerConfig:
    missing = [name for name in REQUIRED_ENV_VARS if not os.environ.get(name)]
    if missing:
        raise ValueError(f"Missing required environment variables: {missing}")

    return AnalyzerConfig(
        api_key=os.environ["ANALYZER_API_KEY"],
        openai_api_key=os.environ["OPENAI_API_KEY"],
        redis_url=os.environ["REDIS_URL"],
        slack_webhook_url=os.environ["SLACK_WEBHOOK_URL"],
        dashboard_url=os.environ["DASHBOARD_URL"],
        dashboard_api_key=os.environ["DASHBOARD_API_KEY"],
```

```python
import hashlib

import redis as redis_lib

DEDUP_TTL_SECONDS = 600


def _dedup_key(event):
    raw = f"{event.server_id}:{event.error_type}:{event.message}"
    digest = hashlib.sha256(raw.encode("utf-8")).hexdigest()
    return f"analyzer:dedup:{digest}"


def is_duplicate(redis_url, event):
    key = _dedup_key(event)
    client = redis_lib.Redis.from_url(redis_url)
    try:
        was_set = client.set(key, "1", ex=DEDUP_TTL_SECONDS, nx=True)
    except redis_lib.RedisError:
        return False
    return not was_set
```

```python
import logging

import requests

logger = logging.getLogger(__name__)


def send_notification(webhook_url, event, ai_analysis):
    text = f"*{event.error_type}* on `{event.server_id}`\n{event.message}"
    if ai_analysis:
        text += f"\n\n*분석*: {ai_analysis}"

    try:
        requests.post(webhook_url, json={"text": text}, timeout=5)
    except requests.RequestException as e:
        logger.warning("failed to send Slack notification: %s", e)
```

```python
import logging

import requests

logger = logging.getLogger(__name__)


def store_error(config, event, ai_analysis, notified, notified_at):
    payload = {
        "server_id": event.server_id,
        "timestamp": event.timestamp,
        "log_level": event.log_level,
        "error_type": event.error_type,
        "message": event.message,
        "stack_trace": event.stack_trace,
        "raw_log": event.raw_log,
        "ai_analysis": ai_analysis,
        "notified": notified,
        "notified_at": notified_at,
    }
    try:
        requests.post(
            f"{config.dashboard_url}/api/errors",
            json=payload,
            headers={"X-API-Key": config.dashboard_api_key},
            timeout=5,
        )
    except requests.RequestException as e:
        logger.warning("failed to store error in dashboard: %s", e)
```

```python
from datetime import datetime, timezone

from analyzer import dashboard_client, dedup, openai_client, slack_client


def process_error(event, config):
    is_dup = dedup.is_duplicate(config.redis_url, event)
    ai_analysis = openai_client.analyze_error(event, config)

    if is_dup:
        notified = False
        notified_at = None
    else:
        slack_client.send_notification(config.slack_webhook_url, event, ai_analysis)
        notified = True
        notified_at = datetime.now(timezone.utc).astimezone().isoformat(timespec="seconds")

    dashboard_client.store_error(config, event, ai_analysis, notified, notified_at)
```

```python
from fastapi import BackgroundTasks, Depends, FastAPI, Header, HTTPException, Request
from pydantic import BaseModel

from watcher.models import ErrorEvent

from analyzer.config import load_config_from_env
from analyzer.processor import process_error


class ErrorIn(BaseModel):
    server_id: str
    timestamp: str
    log_level: str
    error_type: str
    message: str
    stack_trace: str
    raw_log: str


def _check_api_key(request: Request, x_api_key: str = Header(default=None)):
    config = request.app.state.config
    if not x_api_key or x_api_key != config.api_key:
        raise HTTPException(status_code=401, detail="invalid or missing X-API-Key")


def create_app(config):
    app = FastAPI()
    app.state.config = config

    @app.post("/api/errors", status_code=202, dependencies=[Depends(_check_api_key)])
    def receive_error(body: ErrorIn, background_tasks: BackgroundTasks):
        event = ErrorEvent(
            server_id=body.server_id,
            timestamp=body.timestamp,
            log_level=body.log_level,
            error_type=body.error_type,
            message=body.message,
            stack_trace=body.stack_trace,
            raw_log=body.raw_log,
        )
        background_tasks.add_task(process_error, event, config)
        return {"status": "accepted"}

    return app


def app_factory():
    """실제 서버 구동 시 환경변수를 읽어 앱을 만든다.
    실행: uvicorn analyzer.main:app_factory --factory
    """
    return create_app(load_config_from_env())
```
